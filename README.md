# Glean 拾穗

一个中文 Web3 奖励活动研究工作台，针对低门槛、低成本、低耗时、可变现的机会，公开收益、成本、风险与评分依据。

```bash
npm install
npm run dev
```

默认端口 5173。生产构建：`npm run build`；构建预览：`npm run preview`。需要 Node.js 22.18+（建议 24）。

已实现：响应式活动广场、搜索与组合筛选、推荐/耗时/截止排序、收藏、来源详情、参与清单、预期净收益计算器、活动线索本地草稿。收藏和清单持久化到浏览器 localStorage。

当前数据为 **2026-10-26 人工整理快照**，共 7 条活动或历史线索。没有自动采集、账户后端、实时行情或钱包交易。活动提交仅保存本地草稿，界面明确告知尚未发送。适配线上采集时，应先增加服务端审核与来源同步，再开放公开投稿。

重点案例是 **Ptah Relic Genesis**：每 Agent ID 最多 4 枚、可交易；首发已结束。它与不可转让的 Proof of Agent 卡分别收录。历史价格标明来自第三方，未把历史价格、挂牌价或用户收益当作当前可实现回报。

评分与筛选在 `src/model.ts`，策展数据在 `src/data.ts`。未知现金收益封顶 69；高风险或未开放封顶 49；结束活动归档不计分。维度评分属于编辑判断，非审计或投资建议。详细来源见 [研究记录](docs/research.md)。


单元测试覆盖收益成本公式、评分上限与组合筛选；浏览器测试覆盖 Relic/POA 区分、筛选、收藏与清单持久化、计算器、草稿、手机导航。Playwright 会自动启动或复用 5173 端口服务。
